# Learning Feature Design

Read `docs/product/learning-profile-v1.md`, the relevant mission, and `docs/architecture/learning-engine.md`.

1. Define learner level, goal, context, prerequisite, and independent production outcome.
2. Design the context → attempt → selective feedback → changed retry → delayed review loop.
3. Connect the relevant reading, listening, writing, and speaking skills.
4. Define CEFR assumptions, difficulty progression, acceptable variants, hint behavior, and fallback.
5. Declare structured evidence, confidence, learner controls, and profile/recommendation effects.
6. Specify learning metrics, failure cases, ethical gamification, and evaluation fixtures.

Return the activity contract, adaptation rules, event list, acceptance criteria, evaluation plan, risks, and decisions requiring approval. Do not implement or claim learning efficacy without representative evidence.
