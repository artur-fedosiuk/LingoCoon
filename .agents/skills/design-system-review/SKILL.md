# Design System Review

Read `docs/design/visual-system.md` and `$lingocoon-minimal`.

1. Identify changed tokens, primitives, components, states, and responsive behavior.
2. Check typography, spacing, radius, color semantics, focus, motion, and raccoon usage.
3. Verify default, hover, focus, active, disabled, loading, empty, error, and reduced-motion states.
4. Detect one-off styles, duplicated components, copied competitor identity, and decorative AI styling.
5. Compare at narrow mobile and desktop widths without changing product hierarchy.

Return findings by impact with file/component evidence, recommended reuse, accessibility implications, and verification steps. Do not perform a page-by-page reskin or edit code without a separate approved implementation task.
