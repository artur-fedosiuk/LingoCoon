# Adaptive Path Evaluation

## Procedure

1. Identify the deterministic policy, AI contribution, inputs, and persistence boundary.
2. Trace scenarios for new, returning, inactive, uncertain, dismissed, and provider-unavailable learners.
3. Check that repeated evidence outweighs one error and that all four skills receive appropriate opportunities.
4. Test explanation, override, dismissal, expiry, idempotency, and anti-repetition behavior.
5. Check cold start, bias, confidence calibration, accessibility, privacy, and cost failure modes.
6. Define fixtures and measurable outcomes: acceptance, completion, improvement, variety, fallback, and false-priority rate.

Return a scenario matrix, observed gaps, proposed policy changes, metrics, and approval decisions. Keep model inference separate from learner decisions and verified evidence. Do not mutate profile data or recommendation logic without explicit approval.
